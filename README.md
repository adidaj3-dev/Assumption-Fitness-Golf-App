# Crawl · Walk · Run

A personal 12-week at-home fitness and nutrition app. Bodyweight and resistance bands only, 15–20 minute workouts, a gentle walk-to-jog progression, and a simple one-meal-a-day food tracker.

## The program

| Phase | Weeks | Strength circuit | Run days |
|---|---|---|---|
| **Crawl** | 1–4 | 6 moves × 2 rounds, 30s on / 30s off (35/25 in wk 3–4) | Brisk walk → 30–90s jog intervals |
| **Walk** | 5–8 | 7 moves × 2 rounds, 40/20 (45/15 in wk 7–8) | 2–6 min jog intervals |
| **Run** | 9–12 | 7 moves × 2 rounds, 45/15 (50/10 in wk 11–12) | 8 min jogs → **20 min nonstop by week 12** |

Weekly rhythm (counted from your start date): Legs + Core → Walk/Jog → Upper + Bands → Walk/Jog → Full-Body → Mobility (+ optional walk or golf) → Rest + weigh-in.

Every strength session = 3 min warm-up + circuit + 2 min cool-down ≈ 17–20 min. Every move has an easier option.

## Nutrition

- Calorie target = estimated maintenance (Mifflin-St Jeor × 1.45) − 500 ≈ 1 lb/week.
- Protein target = 0.8 g per lb of goal weight.
- Six easy OMAD-sized go-to meals with ingredients and steps, protein add-ons, custom meals, portion multipliers (0.5× steps), water and habit tracking.

## Features

- Today screen with the day's workout, one-tap start
- Full-screen interval timer: countdown beeps, voice cues, "switch sides" prompts, screen stays awake
- 12-week plan view, workout details, mark done
- Weekly weigh-in and waist log with trend chart, streak, adherence and a 12-week map
- Backup/restore (copy and paste), works offline once installed

## Use it on your phone

1. In the GitHub repo: **Settings → Pages → Deploy from branch** and pick the branch, root folder.
2. Open the Pages URL on your phone, then **Share → Add to Home Screen** (iPhone) or **Install app** (Android).

Data is stored on the device (localStorage). Use **Me → Copy backup** occasionally.

Check with your doctor before starting a new exercise or eating plan.
